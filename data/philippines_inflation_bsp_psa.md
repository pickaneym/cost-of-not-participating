# Philippines Inflation Data

Annual average inflation rates for the Philippines, 2015-2025, plus partial 2026 year-to-date data.

Primary source: BSP Table 34, "Inflation Rates", sourced from the Philippine Statistics Authority (PSA).

Source URLs:

```text
https://www.bsp.gov.ph/Statistics/Prices/tab34_inf.aspx
https://www.bsp.gov.ph/Statistics/Prices/Table%2034_2018.pdf
https://www.philstar.com/headlines/2026/05/06/2525950/inflation-surges-72
https://www.rappler.com/business/inflation-rate-philippines-april-2026/
```

Notes:

- 2015-2021 values are from the BSP table using the 2012 CPI base.
- 2022-2025 values are from the BSP table using the 2018 CPI base.
- 2025 is included because BSP/PSA already reports a complete annual average of 1.7%.
- 2026 is included as a partial January-April year-to-date average of 3.9%, based on PSA announcement coverage. It is not a complete annual average.
